# Falabella API
- Always use v2 endpoints for Falabella orders API (`/orders/v2/`, `/manage-orders/v2/`). Confidence: 0.80
- When parsing v2 `GetOrders` responses, unwrap the `Order` property from each element in the `Orders` array — the v2 format is `SuccessResponse.Body.Orders = [{ Order: { OrderId, OrderNumber, ... } }, ...]`, not an array of flat order objects. Confidence: 0.75
- Use v1 (Version=1.0, no path) for `GetOrderItems` calls — the v2 endpoint returns `ErrorCode: "E008" / "Invalid Action"` for this operation. `GetOrderItems` is only available on the v1 API. Confidence: 0.80
- Reuse/extend existing methods in FalabellaApiClient (like `call`) instead of creating parallel methods (like `callPath`) that duplicate parameter-building, signing, and formatting logic. When a new endpoint needs a different URL path, add a `path` option to the existing method rather than creating a new one. Confidence: 0.75
- For Falabella API v2, the `Action` parameter (e.g., `Action=GetOrders`) is still mandatory — consult the official API reference at `developers.falabella.com` for the correct parameter schema instead of assuming REST-style paths. The v2 API uses the same query-parameter style as v1, not RESTful paths. Confidence: 0.85
- Use `deliveryOrderNumber` as the primary order identifier (starts with 3), not `orderNumber` (starts with 1). Confidence: 0.70
- The order detail API (`/manage-orders/v1/order/number/{deliveryOrderNumber}`) returns both the grand total and items inline; no need for a separate items API call. Confidence: 0.65
- To access the order detail API, navigate to `https://sellercenter.falabella.com/order/view/number/{deliveryOrderNumber}` and intercept the `seller-platforms.falabella.services` API call via `page.waitForResponse` rather than calling it directly with `page.evaluate`/`fetch`. Confidence: 0.65
- All Falabella API calls must be encapsulated as methods on `FalabellaApiClient` (e.g., `getOrderItems`, `getOrdersV2`). The desktop IPC handlers should only call these encapsulated methods, never construct `client.call(...)` directly. Confidence: 0.70
